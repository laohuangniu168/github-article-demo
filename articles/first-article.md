# GitHub Pages 第一篇测试文章

这是我通过 GitHub Pages 发布的第一篇测试文章。

## 什么是 GitHub Pages？

GitHub Pages 可以将 GitHub 仓库中的静态内容发布成可以通过互联网访问的网页。

这篇文章使用 Markdown 编写，并保存在 GitHub 仓库的 `articles` 目录中。

## 本次测试的目的

本次主要验证以下发布流程：

**创建 Markdown 文章 → 提交到 GitHub → GitHub Pages 自动部署 → 获得公开文章 URL**

## 后续计划

完成本次测试以后，我们将继续验证：

- 多篇文章发布
- 自动生成 Markdown 文件
- 自动生成文章 URL
- 自动更新文章
- 自动提交 Git Commit
- 自动部署 GitHub Pages

如果这些流程全部验证成功，就可以进一步建立自动化的 GitHub 文章发布流程。
