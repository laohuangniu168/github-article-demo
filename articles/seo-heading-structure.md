# SEO文章H1 H2 H3标题结构优化方法

{% raw %}

## 先理解 H1、H2、H3 各自解决什么问题

标题标签的主要作用，是表达页面内容的层级关系，帮助搜索引擎、读者和屏幕阅读器快速理解文章结构。它们不是单纯用来放大字体的样式工具。

- **H1**：概括整个页面的核心主题，相当于文章主标题。
- **H2**：拆分主要内容模块，回答用户围绕主题产生的几个关键问题。
- **H3**：继续细分某个 H2 下的方法、步骤、场景或注意事项。

例如，一篇介绍“企业网站速度优化”的文章，可以采用下面的层级：

```text
H1：企业网站速度优化方法
  H2：如何检测网站加载速度
    H3：使用 PageSpeed Insights
    H3：查看 Core Web Vitals 数据
  H2：图片体积如何优化
    H3：选择合适的图片格式
    H3：启用懒加载
  H2：服务器响应慢怎么处理
```

这种结构能让读者仅浏览标题，就大致知道文章会解决哪些问题。标题层级清晰不代表页面一定获得更高排名，但有助于内容理解、阅读体验和信息提取。

## H1 应该如何设置

通常建议一篇独立文章保留一个主要 H1，并让它准确描述页面主题。HTML5 规范并未简单禁止多个 H1，但在常见的 SEO 内容页面中，单一且明确的主标题更容易管理，也能减少主题表达上的混乱。

一个合格的 H1 应满足以下要求：

1. 与页面实际内容一致，不使用与正文无关的热门词。
2. 能直接回应目标搜索意图。
3. 包含核心主题即可，不必罗列所有关键词变体。
4. 与其他页面保持差异，避免全站大量页面使用相同 H1。
5. 表达自然，优先让用户一眼看懂。

例如，文章实际讲的是具体操作方法，H1 使用“WordPress 网站图片压缩教程”，通常比“WordPress 图片、网站图片优化、SEO 图片压缩方法大全”更清晰。

还要注意，浏览器标题标签 `<title>` 与 H1 并不是同一个元素。两者可以接近，但不必完全相同：

```html
<title>WordPress图片压缩教程：格式选择与插件设置</title>
<h1>WordPress 网站图片压缩教程</h1>
```

`title` 主要用于搜索结果标题候选和浏览器标签页，H1 则是页面正文中的主标题。可以分别优化，但二者描述的主题不能互相冲突。

## 用 H2 覆盖搜索意图，而不是堆积关键词

H2 决定了文章主体如何展开。规划 H2 时，应先分析用户搜索主关键词后还想知道什么，再将这些问题组织为几个相对独立的内容模块。

常见的拆分方式包括：

- **按操作流程拆分**：准备、设置、检查、发布。
- **按问题拆分**：原因、解决方法、常见错误。
- **按对象拆分**：新手网站、电商网站、内容网站。
- **按决策过程拆分**：适用场景、成本、优缺点、选择建议。
- **按搜索需求拆分**：是什么、怎么做、是否有效、如何验证。

例如，围绕“网站内链优化”，可以设计：

```text
H2：内链对网站内容有什么作用
H2：如何选择适合添加内链的页面
H2：锚文本应该怎样写
H2：每篇文章添加多少内链合适
H2：如何检查失效链接和孤立页面
```

这些 H2 分别承担不同任务，比反复使用“网站内链优化技巧”“SEO 内链优化方法”“内链 SEO 教程”更有信息价值。

H2 数量没有统一标准，应由内容复杂度决定。对于常规教程，4～7 个主要模块通常比较容易阅读；如果一个 H2 下只有一两句话，可能说明拆分过细，或者该部分没有成为独立章节的必要。

## H3 应在什么情况下使用

当某个 H2 包含多个并列步骤、工具、类型或子问题时，可以使用 H3。H3 必须从属于上方最近的 H2，不能脱离上下文独立出现。

### 适合使用 H3 的情况

- 一个方法需要拆成多个操作步骤。
- 同一问题存在多个解决方案。
- 需要分别介绍不同工具或平台。
- 一个章节同时包含配置方法与检查方法。
- 内容较长，需要降低连续阅读压力。

### 不需要使用 H3 的情况

如果一个 H2 下只有一段简短说明，通常没有必要再添加 H3。标题过多会让文章变得零碎，也可能让每个章节缺乏足够内容。

层级最好按顺序使用，不要为了字体大小直接从 H2 跳到 H4。正确做法是通过 CSS 控制视觉样式，通过标题标签表达语义：

```html
<h2>如何检查页面标题结构</h2>
<h3>使用浏览器开发者工具</h3>
<h3>使用 SEO 检测工具</h3>
```

如果 H3 看起来太小，应修改 CSS，而不是把它改成 H2。

## 关键词如何自然分配到各级标题

核心主题通常出现在 H1 中，H2 和 H3 则可以使用相关问题、属性词和具体场景。没有必要让每一个标题都重复完全相同的关键词。

可以参考以下分配方式：

| 标题层级 | 主要内容 | 示例 |
|---|---|---|
| H1 | 页面核心主题 | 电商网站产品页 SEO 优化指南 |
| H2 | 主要子问题 | 产品标题应该如何编写 |
| H2 | 主要操作模块 | 商品图片的 SEO 设置 |
| H3 | 具体方法 | 编写有描述性的图片文件名 |
| H3 | 具体方法 | 设置准确的 alt 文本 |

标题中的关键词应服从语义和可读性。如果某个词放进去后明显生硬，可以换成用户常用的自然问法。搜索引擎能够结合正文和上下文理解主题，不需要依靠机械重复来证明页面相关性。

同时避免使用只有吸引力、没有明确含义的标题，例如“你绝对想不到的秘密”“最完整的方法来了”。教程型内容更适合直接说明章节价值，如“如何检查重复 H1”或“标题层级错误怎么修复”。

## 发布前检查标题结构

文章完成后，不要只看编辑器中的视觉效果，还应检查网页最终生成的 HTML。部分主题、页面构建器或插件可能自动添加标题标签，导致作者没有察觉的重复 H1。

可以按照下面的清单检查：

1. 页面是否有明确的 H1。
2. H1 是否与正文主题及搜索意图一致。
3. 网站 Logo、侧边栏标题是否被错误设置成 H1。
4. 主要章节是否使用 H2，而不是加粗普通段落。
5. H3 是否确实属于某个 H2。
6. 是否存在无实际内容的空标题。
7. 标题文字是否简洁、具体并能概括下方内容。
8. 移除正文后，仅阅读标题能否理解文章逻辑。

在浏览器中右键选择“检查”或“查看网页源代码”，搜索 `<h1`、`<h2` 和 `<h3`，即可确认实际输出。也可以在开发者工具控制台执行：

```javascript
[...document.querySelectorAll('h1,h2,h3')].map(el => ({
  level: el.tagName,
  text: el.textContent.trim()
}))
```

这段代码会列出页面中的主要标题及其层级，便于发现重复、缺失或顺序异常。自动化 SEO 工具也能辅助检查，但最终仍需人工判断标题是否准确反映内容。

## 一套可直接使用的文章结构

多数教程型 SEO 文章可以从下面的框架开始，再根据主题删减：

```text
H1：核心主题 + 内容类型或明确结果
  H2：基本概念或适用场景
  H2：开始操作前的准备
  H2：核心操作方法
    H3：步骤一
    H3：步骤二
    H3：步骤三
  H2：如何检查操作结果
  H2：常见错误与解决方法
  H2：补充建议或选择依据
```

这不是必须照搬的固定公式。真正有效的结构，应由用户问题和内容逻辑决定：H1 明确整页主题，H2 承担主要信息模块，H3 负责必要的细分。发布前再检查 HTML 输出、层级顺序和标题可读性，通常就能避免大多数标题结构问题。
