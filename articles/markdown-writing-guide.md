# Markdown 文章写作基础教程

Markdown 是一种适合编写网页内容的轻量级标记语言。

## Markdown 标题

文章可以使用不同级别的标题组织内容。

一级标题用于文章主题，二级和三级标题可以用于不同章节。

## Markdown 列表

Markdown 支持列表，例如：

- GitHub Pages
- Markdown
- 静态网站
- SEO 内容

## Markdown 链接

文章之间可以通过链接建立关联。
