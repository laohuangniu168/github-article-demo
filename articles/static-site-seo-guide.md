# 静态网站 SEO 优化基础指南

静态网站同样可以通过合理的网站结构和内容组织改善搜索引擎友好性。

## 页面标题

每个页面应该拥有与正文主题一致的标题。

标题应该能够清晰表达页面主要内容。

## 页面 URL

文章 URL 应尽量保持清晰和稳定。

例如：

/articles/static-site-seo-guide.html

这种 URL 可以直接表达文章主题，也方便后续管理。

## 内容结构

文章可以使用 H1、H2 和 H3 等标题层级组织内容。

合理的内容结构可以提高文章的可读性。

## 内部链接

相关内容之间可以建立内部链接，让不同文章形成内容关联。
