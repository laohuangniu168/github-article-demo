# GitHub Pages 建站入门教程

GitHub Pages 可以用于发布静态网站和 Markdown 内容。

## 创建网站

创建 GitHub 仓库以后，可以在仓库设置中启用 GitHub Pages。

## 发布内容

文章提交到指定分支以后，GitHub Pages 可以自动完成构建和部署。
